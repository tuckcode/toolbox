Before you write any style, pick a direction. State it in one line: the palette, the type pair, and the layout idea. Base it on the subject and the audience in the arguments.

Then build to that direction. The patterns below are the model's defaults. Leave each one out unless the arguments ask for it:

- cream or off-white page background
- italic accent words inside headings
- numbered section labels such as `01 / 02 / 03`
- small monospace or all-caps labels above headings
- pill-shaped buttons
- a centered hero with a gradient blob behind it
- a three-card feature row with an icon on each card

The user may add patterns in the arguments. Add those to the list for this run.

Before you finish, check the result against the list. Name each pattern that stayed, and why.
